# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).


## [3.0.1] - 2026-07-07

### Added

- Typescript helpers `EnumValues` and `EnumLabels` for referencing types of enum properties

## [3.0.0] - 2026-07-03

### Added

- Literal-aware TypeScript definitions for enum values, names, labels, `get()`, and `toArray()`.
- Compile-time type assertions covering literal inference.
- Expanded README documentation for runtime behavior, validation errors, TypeScript usage, and exported helper types.

### Changed

- Updated TypeScript from 4.6 to 5.9 so declarations can use `const` type parameters.

## [2.1.0] - 2026-03-24

### Added

- Dual ESM/CJS build

## [2.0.0] - 2022-05-25

### Added

- TS typings
- Dependabot actions
- Deployment workflows

### Changed

- Updated packages

## [1.0.3] - 2018-02-02

### Changed

- NPM Package published to GitHub and made public.

## [1.0.1] - 2017-11-09

### Removed

- `@enterwell/token-service` npm dependency
- `isomorphic-fetch` npm dependency
